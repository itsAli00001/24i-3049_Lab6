# Week 6 AI Lab — Informed Search

## Streamlit files
- `app.py` — Streamlit GUI
- `searchAlgos.py` — hospital graph, Euclidean heuristic, GBFS and A*
- `requirements.txt` — deployment dependencies

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy
Push these files to a GitHub repository and deploy `app.py` using Streamlit Community Cloud.

The GCR submission requires:
1. The completed `.ipynb` file.
2. The GitHub repository link containing the Streamlit code.
3. The deployed Streamlit app link.

Do not clear notebook outputs before downloading/submitting the notebook.
